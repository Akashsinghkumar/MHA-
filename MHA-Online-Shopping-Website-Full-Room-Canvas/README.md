MHA Online Shopping Website

Run locally:
1. Install Node.js (18 or newer).
2. Open this folder in a terminal.
3. Run `npm install` once, then `npm run dev`.
4. Open the local URL printed by Vite.

The site is deployed automatically to GitHub Pages when changes are pushed to `main`:
[https://deepak172003.github.io/MHA/](https://deepak172003.github.io/MHA/).

The site includes separate Home, Shop, Furniture, Electronics, EV Scooters, Accessories, Offers, Gallery & Videos, Support Centre and account pages. Product images use consistent card sizing.

Admin Panel demo sign-in: `admin` / `MHAAdmin123!`.
Admin product, offer, gallery, FAQ, policy, order status and support request changes save to this browser's local storage. Gallery customer uploads remain pending until approved. The demo support forms generate local ticket, warranty and service IDs, and order tracking uses statuses entered by the admin. WhatsApp/email/phone are contact links; sending automatic email notifications requires a connected backend and email provider.

This is a front-end demo. Browser storage is local to each browser/device; it does not synchronize users or provide server-side authentication.
